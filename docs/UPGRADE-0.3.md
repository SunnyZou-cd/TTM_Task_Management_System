# 0.3 升级说明

## 版本定位

0.3 是预览版，用于验证日程、Markdown 编辑和 Windows 桌面模式的组合工作流，尚未作为正式稳定版发布。安装包为 `release/Pinboard-0.3.0-Setup.exe`。

## 使用说明

1. 运行安装包并启动应用。首次数据库写入前会生成 `database.pre-0.3.json`。**成功标志：主窗口显示任务列表，数据目录中保留首次写入前备份。**保留这份备份，恢复前先复制当前数据目录。
2. 在默认待办列表中创建或编辑任务；任务完成后自动归档，可切换到“已归档”视图恢复任务，也可按标签筛选、搜索和排序。列表每页最多 50 项。**成功标志：筛选和翻页后的条目与条件相符。**
3. 为任务设置每天、每周或每月的固定日程。生成依照日程时间，不依赖上次任务是否完成；应用每 30 秒检查一次。下次启动最多补生成最近 30 次，停止循环后不再生成后续任务。**成功标志：日程触发后任务出现。**
4. 在主界面查看 Markdown 源码或预览；固定便笺可直接修改渲染后的文字并保留文档结构，格式操作在主界面完成。**成功标志：保存并重新打开后内容一致。**
5. 在日历中选择日期查看放大视图，月视图显示缩略概览；Ctrl/Shift 可多选日期，也可切换为单日选择。**成功标志：选择变化后日历显示对应日期。**
6. 从侧栏或设置窗口使用固定入口，并在设置中选择主界面普通窗口或桌面模式。**成功标志：主界面按所选模式显示。**桌面模式的真实 HWND 附着、解除附着和辅助进程退出恢复已通过验证；Win+D 行为尚待实机验证。

## 验证状态与限制

截至 2026-10-15，50 项单元测试、生产构建及运行时依赖审计（0 项报告）已通过。桌面关闭/恢复、355 条任务工作流、日历多选和 Markdown 编辑保留格式已通过；打包程序启动与保存已通过。

待验收项：邮箱投递、数据库 schema 执行、跨设备同步和线上账号隔离。配置前请检查所选服务的费用与配额。

## 技术结构

0.3 延续 Electron、React、TypeScript、Vite 和可选 Supabase 的技术栈。窗口与桌面集成通过原生宿主接口及有限 preload/IPC API 连接界面；模块边界和后续扩展建议见[模块化说明](MODULARITY.md)。
