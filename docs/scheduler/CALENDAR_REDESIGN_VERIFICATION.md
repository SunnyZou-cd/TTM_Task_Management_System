# 日历改版验收 · 2026-11-16

用户确认移除独立Time页面，以日历空白自动排程，并直接管理忙碌事件。默认英文和会话内简体中文切换保留。

## 实际结果

- 主窗口为任务侧栏、日期导航和Canvas周/日日历，无Tasks/Time/Plan分页。File菜单收纳存档操作，低频设置独立打开。
- 任务弹窗仅名称、总分钟、截止时间为主要字段；剩余默认跟随总分钟，其他字段可展开。日历空白创建忙碌时段，已有色块打开编辑/锁定详情。
- generate_calendar使用当前有效规划窗口的全部空白，扣除busy/locks；比较不改数据，导航不改规划范围。没有暗中指定9–18作息，夜间也属于空白。
- 旧存档加载不自动写回；生成成功才更新内存中的availability，保存沿用备份和冲突检查。终端/JSON原契约不变。

## 自动与可见验证

Windows / Python 3.14.3 / Tk 8.6，完整unittest 98项通过（日志work/calendar-review/full-test.log），含12项真实Tk GUI测试及新增3项日历工作区测试。单文件已重新生成，默认GUI、隔离运行、语言切换和JSON/终端回归通过。

GUI检查覆盖任务默认值和双语、空白点选、busy增改删/编辑失败回滚、生成后定位首块、锁定解锁、日期导航仅改变视图、设置事务性以及无修改Apply不清空计划。独立只读审查进一步验证滚动坐标、跨午夜/跨周显示、busy与锁定冲突保持原状态。

DST不存在/歧义的空白点击拒绝静默创建；回拨事件显示起止UTC偏移与实际分钟数。正常24小时网格不是对25小时日的等比例重排，回拨详情通过明确偏移和时长辨别。
