# 日历工作区改版 · 2026-11-16

## 用户确认

- 参考Google Calendar的日期导航、日/周视图、在日历创建和查看事件的操作方式。
- 砍掉独立Time页面。自动排程使用规划范围内的日历空白，忙碌事件直接在日历中管理。
- 保留默认English与English/简体中文选择。用户任务标题不翻译。
- 课程目录作为实现参考，具体对应见COURSE_ALIGNMENT.md；本轮不增加数据库或分析库的操作负担。

## 实现

主窗口只保留任务侧栏、日期导航和日历网格，移除旧Tasks/Time/Plan三页填表布局。任务编辑按需打开简短表单；新任务默认remaining=estimated，低频字段放高级选项。文件操作收进菜单，Generate为主要操作；策略、规划范围及时区收进设置。点击空白可管理忙碌事件，点击安排查看和锁定/解锁。

Workspace新增generate_calendar/compare_calendar，以整个当前有效规划区间为容量，再扣除busy和locks。生成前不改存档，生成失败不部分修改；保存时延续.bak备份与并发冲突保护。旧JSON CLI/终端保持旧契约。浏览日期不改变规划窗口，不在过去安排新块。

全部空白包含夜间；用户可在日历标记不希望排程的忙碌时段。不得暗中推断用户作息或声称已掌握真实课程安排。

实现状态：已完成。98项完整回归及可见窗口检查通过，详情见[CALENDAR_REDESIGN_VERIFICATION.md](CALENDAR_REDESIGN_VERIFICATION.md)。
