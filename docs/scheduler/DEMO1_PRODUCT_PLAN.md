# Demo 1 软件交付计划 · 2026-11-15

## 目标

交付能实际管理个人任务并生成学业计划的 Python 终端软件。默认启动进入空白工作区和操作菜单，不自动运行预设案例。用户通过提示录入任务和时间，选择策略，查看结果，锁定重排，保存后退出并重新打开继续使用。原有合成案例保留为显式演示选项。

单文件 `demo1.py` 继续是交付入口；不要求用户编辑JSON或安装本项目包。默认UTC；使用其他IANA时区需系统时区数据或tzdata。没有图形窗口、Electron联动、外部账户或真实数据库操作。

## 操作流程与验收

1. `python demo1.py`进入主菜单，首次没有任务和预设计划；显示当前存档路径及未保存状态。
2. 新建、查看、修改、删除任务；设置总/剩余分钟、重要性、截止、最早开始、可拆分；记录进度和明确标记完成。
3. 设置规划起止及展示时区；增删可用/忙碌区间。日期可以按提示输入本地年月日时分；DST歧义要求显式偏移。
4. 选择EDF / Importance First / Risk-Aware及块长，生成计划并查看任务标题、时间块、未排分钟和中文原因；同输入比较三策略。
5. 锁定计划块、查看和解除锁定；重新生成只替换未锁定部分。数据修改会使旧计划失效，不能拿旧计划锁定新输入。
6. 生成计划时使用不早于实际当前分钟的起点。已开始锁定块不能默默当作完成；需先解除锁定并核对剩余工作量。
7. 手动保存/加载；退出有未保存数据时提示保存、放弃或取消。存档失败保留当前内存数据；损坏存档不会被自动覆盖。
8. 保存采用原子替换、旧文件备份和并发修改检测。测试全在work/，默认个人存档work/demo1-data/workspace.json不进Git。
9. 自动验收完整输入操作→生成→锁定→修改→重排→保存→重启→加载的用户流程，不以预设案例运行替代软件验收。
