# 本机时间更新 · 2026-11-16

界面已移除时区选择和状态栏时区文字，日期导航、日历、任务、忙碌时间与规划设置均使用电脑的本地时间。输入/表单显示为YYYY-MM-DD HH:MM，不要求选择IANA名称。默认English及中文切换保留。

内部仍按UTC校验和计算，系统本地规则按具体日期查询；没有将当前固定偏移用作全年时区。GUI读取旧存档时仅在内存转换显示偏好，不更改任务、锁定、版本或实际时刻；未保存不写盘，显式保存保留旧bytes的.bak备份。JSON/终端的原IANA和UTC兼容接口保留。

## 验证

Windows / Python 3.14.3 / Tk 8.6 全套104项unittest通过，日志work/local-time-review/full-test.log。单文件已重新生成且同步检查通过，用户原有文件头保留。

新增检查包括：与本机标准库逐日期转换比较；模拟Chicago冬夏偏移及回拨的两个绝对时刻；不存在/歧义本地输入拒绝；无需ZoneInfo数据即可使用本机时间；系统日期越界转为输入错误；旧IANA存档无需对应数据即可显式加载本机视图、原文件不变且保存备份精确；真实Tk表单本地时间、无时区字段、直接Apply不使计划失效、旧任务/忙碌事件无修改提交保持绝对时刻。

原终端流程测试的UTC合成输入改为显式偏移，避免在本机默认值下把UTC测试日期误当本地日期。未改动测试的成功标准。

新工作区的内部timezone值为local，属于本机显示标记；不是新增给用户选择的时区功能。严格Workspace/Store默认加载保持原契约，GUI显式选择本机显示。测试仅使用work/合成数据，未操作用户真实存档，未实测其他系统。
