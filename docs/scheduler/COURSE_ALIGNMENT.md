# 课程内容与本项目的对应

依据：用户于2026-11-16提供的两张课程目录截图。截图说明学习范围，不等于项目评分rubric，也没有说明所有模块都必须使用。

| 课程模块 | 项目中的用途 | 范围 |
| --- | --- | --- |
| 1 Python基础 | 函数、字符串、列表/元组/字典、输入验证 | 已有调度与工作区基础 |
| 2 函数式编程 | 排序key/lambda、推导式、生成器表达式 | 已有区间和策略代码；不为展示语法强加装饰器 |
| 3 系统编程 | 文件/目录、读写、临时文件、原子替换 | 已有本地存档与备份 |
| 4 类与对象 | dataclasses、Workspace/Store、GUI类与方法 | 已有结构，便于单独讲解职责 |
| 5 GUI/Tkinter | Canvas日历、Button、Entry、Checkbutton、Frame、Label、Menu | 当前日历改版直接应用 |
| 6 持久化与数据库 | SQLite CRUD/查询/commit/rollback/close | 潜在后续扩展；当前JSON存档不声称已覆盖数据库要求 |
| 7 Pandas/NumPy | 跨案例三策略结果的汇总分析 | 后续正式实验可按需要采用；不声称当前已使用 |
| 8 SciPy图像处理 | 与核心日历调度缺少直接关系 | 当前不纳入，不虚构应用 |
| 9 软件开发 | 调试、unittest、真实Tk与存档回归 | 已有自动测试；当前改版继续验证 |

当前优先目标仍是参考Google Calendar降低操作成本，移除Time页面，直接在日历操作任务和忙碌事件。新增课程库应服务具体功能，不能仅为覆盖课程目录增加用户负担。
