# Pinboard

Pinboard 是 Windows 任务管理与桌面便笺应用。0.3 为预览版，尚非正式稳定发行。

## 安装与开始

1. 运行 `release/Pinboard-0.3.0-Setup.exe`，按安装向导完成安装后启动 Pinboard。安装会写入所选程序目录并创建快捷方式；Windows 可能提示未知发布者。**成功标志：主窗口打开并显示任务列表。**首次启动会在应用数据目录写入数据前保存 `database.pre-0.3.json`；请保留该备份。
2. 在侧栏选择“待办”或“已归档”，可按标签筛选、搜索并排序；完成的任务会自动归档。列表每页最多显示 50 条，使用分页查看后续结果。**成功标志：列表内容随筛选条件更新，翻页可见后续任务。**
3. 新建任务并填写标题；需要时添加标签、日程或 Markdown 正文。**成功标志：保存后任务出现在列表中，刷新或重启后仍可见。**
4. 从日历选择日期查看安排；Ctrl/Shift 可多选日期，也可切换单日选择。单击日期可放大该日，月视图保留缩略概览。**成功标志：日程随所选日期更新。**
5. 在任务中设置每天、每周或每月的固定日程。日程生成不依赖前一次任务是否完成，应用每 30 秒检查一次；下次启动最多补生成最近 30 次。停止循环后不再生成后续任务。**成功标志：后续任务按固定日程出现。**
6. Markdown 内容可在主界面切换源码和预览；固定便笺中可直接修改渲染后的文字并保留 Markdown 结构，格式操作在主界面完成。**成功标志：预览显示格式化内容，保存后重新打开内容一致。**
7. 点击图钉固定便笺；在设置中选择主界面显示为普通窗口或桌面模式。**成功标志：主界面按所选模式显示。**桌面模式通过 Windows 原生窗口附着实现，程序已验证附着、解除附着及辅助进程退出后的恢复；Win+D 行为尚待实机验收。

侧栏和设置窗口可从固定入口打开。完成任务会自动归档，之后可在“已归档”中恢复。

## 云端配置

邮箱验证码登录和 Supabase 同步需要你自己的 Supabase 项目。按[云端配置指南](docs/CLOUD_SETUP.md)设置项目 URL 和客户端公开密钥。不要填写数据库密码、secret key 或 service_role key。未配置云端时仍可使用本机工作区。

**待真实服务验收：**邮件投递、SQL 执行、跨设备同步和线上账号隔离。配置前请查看所选服务的费用与配额。

## 数据与恢复

正式数据保存在 Windows 用户应用数据目录；具体路径随安装版或开发版的应用名称而异。进行 0.3 首次数据写入前会创建 `database.pre-0.3.json`。请退出应用后再复制数据目录；恢复前先保留当前目录，并将备份放回对应位置。损坏数据会阻止应用启动以避免空数据覆盖，请先复制留存再处理。

## 开发

需要 Node.js 24。在 PowerShell 中运行以下命令会克隆代码、下载依赖并启动开发版；依赖安装会联网并写入项目的 `node_modules`。

```powershell
git clone https://github.com/SunnyZou-cd/TTM_Task_Management_System.git
Set-Location .\TTM_Task_Management_System
npm ci
npm run dev
```

**成功标志：**Pinboard 开发窗口打开。技术栈与模块边界见[模块化说明](docs/MODULARITY.md)，架构与验证口径见[架构说明](docs/ARCHITECTURE.md)。
